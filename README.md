# DSH Thinking Effort Slide Bar

[![npm 版本](https://img.shields.io/npm/v/dsh-thinking-effort-slide-bar)](https://www.npmjs.com/package/dsh-thinking-effort-slide-bar)

npm 包：[dsh-thinking-effort-slide-bar](https://www.npmjs.com/package/dsh-thinking-effort-slide-bar)

为 **DeepSeek Harness 官方桌面版**提供思考强度滑动条：拖动选择档位，松手确认；随着强度提高，绿色轨道逐渐加入金色与粉色光效，星尘沿轨道流动。

**1.5.6** 适配 **DSH Desktop 0.2.1-rc.2**，同时保留 `0.2.0-rc.2` 的配置接口兼容；新增插件详情设置，以及官方 DeepSeek 测试版本徽标。

## 插件设置

打开桌面端的 **插件 → 已安装 → DSH Thinking Effort Slide Bar 插件详情**，即可调整下列选项，点击 **保存设置** 后立即生效。设置由桌面端保存，适用于当前 profile 下的所有对话，重启后保留。

| 设置 | 可选值 | 默认值 |
| --- | --- | --- |
| 显示模型版本徽标 | 开 / 关 | 开 |
| 动效模式 | 跟随系统 / 减少动效 / 关闭动效 | 跟随系统 |
| 强度名称语言 | 英文 / 中文 | 英文 |
| 显示模型说明悬浮提示 | 开 / 关 | 开 |
| 紧凑布局 | 开 / 关 | 关 |

“减少动效”关闭星尘和扫光，保留吸附过渡；“关闭动效”同时取消动画与过渡。系统要求减少动态效果时始终尊重系统偏好。紧凑布局缩小间距，保留模型名称、版本徽标和档位。中文档位依次为“关闭、极低、低、中、高、超高、最高”，只改变显示，不改变提交给模型的强度值。

关闭模型说明悬浮提示后，仍可悬浮查看完整模型 ID，也会继续显示附件兼容和选择失败提示。“恢复默认值”先恢复表单，点击保存后生效；保存失败会保留编辑内容，便于检查后重试。

## 模型版本徽标

收起入口、展开面板的当前模型行和模型列表统一显示版本，例如 **DeepSeek-V4.1-Flash `1017`**。悬浮模型名称可查看完整模型 ID。

版本来源有两种：

- 模型名称或 ID 明确携带版本后缀，例如 `deepseek-v4.1-flash-1017`。
- 新版官方 Flash 模型当前生效的版本标签及其字典。仅对官方 provider 的 `deepseek-flash`、`DeepSeek-V4.1-Flash` 组合读取该信息，其他模型不会套用它的版本。

官方 `0.2.1-rc.2` 的 `1017` 由临时标签插件展示，并非模型目录中的版本字段。当前适配通过公开的插槽元数据和字典查询读取实际标记，没有固定写入 `1017`，也不调用官方组件或重复声明其子插槽。此适配依赖官方临时标签插件的命名约定；标签或字典不可用时不推测版本，明确的模型 ID 后缀仍可展示。

## 可视化效果

![思考强度滑动条：展开、连续拖动、吸附及浅深主题](screenshots/effort-slider-v1.5.5.gif)

GIF 使用本项目的实际前端组件录制，展示连续拖动、高档星尘与浅深主题切换。

| 状态 | 界面表现 |
| --- | --- |
| 收起 | 显示当前模型名称和已生效的思考档位。 |
| 展开 | 底部入口显示 **“选择强度”**；面板保留模型选择行、当前档位和滑动条。 |
| 拖动 | 旋钮与填充即时跟随指针，档位名称提示最近的位置。 |
| 松手 | 以 180 毫秒吸附到最近档位，只提交一次选择。 |
| 中高强度 | 绿—金—粉渐变逐渐增强，星尘最多 18 颗，流动速度随强度提高。 |
| 最高档 | 保留真实档位名称，并显示“使用更深更强的思考”。 |
| 减少动态效果 | 保留静态渐变与档位信息，停止星尘、扫光和位置过渡。 |

鼠标、触摸和触控笔均可拖动；键盘方向键逐档调整，Home / End 到达两端。可用档位来自当前模型，支持不同数量的档位；只有一个档位时仅展示，不播放动态光效。

## 安装到官方桌面版

### 安装 DeepSeek Harness

从 [DeepSeek 官方下载页](https://www.deepseek.com/download/) 下载适用于 Windows 或 macOS 的 **DeepSeek Harness 桌面端**，安装后先启动一次，完成初始化。可在应用菜单“关于 DeepSeek Harness”中查看版本。

本版本的主要适配目标为官方桌面端 **0.2.1-rc.2**。已对照新旧版本的设置与插槽源码；开发验证覆盖真实 Host 配置 schema、客户端接口适配及浏览器界面。这些验证不等同于在用户真实桌面会话中完成安装实测。

### 通过插件页面安装

1. 打开官方桌面端的“插件”页面，选择添加插件。
2. 输入本项目的 **npm 包名**：

   ```text
   dsh-thinking-effort-slide-bar
   ```

3. 安装完成后，完全退出并重新打开桌面端。
4. 点击输入框底部的模型入口，看到“选择强度”与滑动条后即可使用。

安装源可以选择“npm 官方源”或“中国大陆镜像源”。需要固定本次版本时，填写 `dsh-thinking-effort-slide-bar@1.5.6`。这里不需要添加 GitHub 用户名前缀；新版本发布后，镜像源同步可能存在延迟。

本项目的 [npm 页面](https://www.npmjs.com/package/dsh-thinking-effort-slide-bar) 提供已发布版本信息。也可在插件页面选择本地安装 `.tgz` 包；本地开发包可运行 `npm pack` 生成。从 [v1.5.6 Release](https://github.com/SuShuheng/dsh-thinking-effort-slide-bar/releases/tag/v1.5.6) 下载安装包，或通过 `github:SuShuheng/dsh-thinking-effort-slide-bar#v1.5.6` 安装。

本地开发中的版本可以直接添加本项目所在的目录。安装后同样需要完全退出并重启桌面端。

### 使用桌面端自带的 dsh 命令

官方桌面端的应用菜单提供“管理 dsh 命令…”。从这里安装命令后，打开新终端运行 `dsh --version` 确认；无需另装 Node.js 或 pnpm。

先启动一次桌面端完成初始化，再**完全退出桌面端**，使用它自带的命令安装本项目：

```powershell
dsh plugin --profile desktop add dsh-thinking-effort-slide-bar@1.5.6
```

安装后重新打开桌面端。这里需要使用官方桌面端提供的 dsh 命令；单独通过 npm 安装的 dsh 不能管理官方 Desktop profile。

相关安装行为以 [官方桌面端说明](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-rc.2/apps/desktop/README.zh.md#终端命令) 为准。

## 本项目开发记录

本项目围绕输入区的模型选择与思考强度调整持续迭代：先完善档位排序和模型菜单，再增加最高档光效，随后将拖动和动画改为连续、渐进的反馈。

| 版本 | 本项目的改进 |
| --- | --- |
| 1.5.0 | 扩展思考强度词表，支持 off、minimal、low、medium、high、xhigh、max，以及模型声明的档位子集。 |
| 1.5.1 | 改善模型名称布局和悬浮说明，处理窄屏下说明框的位置。 |
| 1.5.2 | 将模型列表与强度滑条整合进同一个浮层，两个视图互相切换。 |
| 1.5.3 | 为最高可调档位加入绿—金—粉渐变和细小光点，并支持减少动态效果。 |
| 1.5.4 | 加入连续拖动、180 毫秒吸附、渐进星尘、档位文字颜色联动、失败回退与键盘焦点恢复。 |
| 1.5.5 | 展开时统一显示“选择强度”；正确处理官方新版的选择失败结果；适应新版附件 ID，避免把普通文件认定为图片；完整重写项目介绍、官方桌面端安装说明和动态预览。 |
| **1.5.6** | 适配 0.2.1-rc.2；插件主详情页新增五项可持久化设置、失败重试及恢复默认值；三处统一展示官方模型版本徽标，支持显式模型 ID 版本后缀；保留 0.2.0-rc.2 配置接口兼容。 |

当前开发检查覆盖展开与收起状态、不同档位数量、连续拖动与取消、提交失败和延迟确认、键盘焦点、浅深主题及减少动态效果；1.5.6 另覆盖 Host schema、设置保存失败与重试、只读状态、恢复默认值、服务卸载、版本来源更新与窄屏布局。
